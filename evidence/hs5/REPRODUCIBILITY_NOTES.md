# HS5 Reproducibility Pass — Notes (2026-11-08)

**Question.** Can someone who has only the public repository and the README
install PPETS, run it, and get the published outputs?

**Method.** The README was followed literally ("peer-style simulation"), in
throwaway clones and brand-new virtual environments on the reference
machine. Nothing from the development interpreter was reused. Every failure
was logged before it was fixed. The fixed state was then re-run with an
automated script, so the pass can be repeated by anyone:
`python validation/hs5_clean_run.py`.

## What this pass did not cover

- **Other operating systems.** Only Windows 11 was run. The CI workflow
  (`.github/workflows/ci.yml`) adds Ubuntu with Python 3.14 and 3.11, but it
  has not run yet, because it runs only after a push.
- **Another machine or another person.** This was a self-run peer
  simulation on the development machine, in fresh clones. A real second user
  would be the next step.
- **Containers.** Docker was not installed, so no image was built and no
  untested Dockerfile was added.
- **Manual GUI use.** The GUI is exercised programmatically (V09, V10, Qt
  tests) and will be shown in the walkthrough recording. There is no
  scripted click-through.
- **Full study regeneration.** Two of 18 published study files were
  regenerated (about 1.5 minutes). The rest would take about 1.5 hours; the
  gate and the procedure are in RUNBOOK §4.
